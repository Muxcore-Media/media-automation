# Roadmap

- [x] Wanted items queue with SQLite persistence
- [x] Search integration (search via searcher-module)
- [x] Quality scoring engine
- [x] Download dispatch (via http-downloader)
- [x] Download history tracking
- [x] Periodic RSS sync loop

- [ ] Custom format definitions
